## 5. Notes

1. All 58 GSTR-2B credit notes are "Not in Rec" - the software records contain no debit note entries; the book-side debit note entries live in the separate DEBIT NOTE register (main project reconciliation), so part of this pool is that timing/registration gap.
2. CESS is zero throughout; R1 Date is the supplier GSTR-1 reporting date (reference only).
3. "Partly Matched" = matched on invoice no/GSTIN with differences (amounts and/or date/POS).
4. Every bridge line can be drilled down in sheet A2 (filter by Month + Line); totals tie out exactly to sheet A.
